# 观市 Market Watch

用户于2026-11-15选定 graphite 深色双栏手稿并要求按此制作。独立项目，不改现有五个仓库。第一版先本地运行与验证，提供 Git/Docker 发布所需文件。

## 核心体验
桌面：紧凑自选列表 + 右侧行情/曲线/统计；手机：自选列表进入详情、清楚返回；平板保留双栏。自选可按全部、股票、加密、黄金分类，搜索名称/代码/市场，添加、删除、排序。支持最多50个自选，默认8个示例标的。价格均为真实供应商数据，绝不使用手稿示例报价回填生产。

## 隐私
自选标的、排序、选中项、主题、涨跌配色、刷新间隔仅在设备localStorage。导入导出版本化JSON，限制大小和数量，校验标识。不建账号、不上传保存自选清单。服务端只有公开行情内存缓存，限量、限时；请求日志不记录查询和正文。密钥只通过部署环境传给服务器，不进入浏览器偏好。

## 架构
Go标准库单进程内嵌Vue3/TypeScript/Vite；ECharts按需模块化绘图。无数据库。固定上游域名，有限响应、超时、重定向禁用、共享缓存、单飞请求、并发上限与退避。浏览器切换标的/区间取消旧请求并验证最新序列；离线与旧缓存清楚标记。

## 数据
股票/指数/ETF：Yahoo Finance公开chart/search接口，query1/query2是同来源两条线路，不声称独立行情服务或交易所授权实时数据。个人自托管实验性适配，可能限流或调整，公开服务/商用应另核实授权并替换适配器。加密：Coinbase公开产品报价与K线，标明具体USD交易对和24小时口径。现货黄金/白银：Gold API，美元/金衡盎司；当前报价免Key，历史接口需要 GOLD_API_KEY，免费历史额度10次/小时，服务器全局限额并缓存。无Key不画假曲线、不以GC=F期货替代。新增资产保留交易所、币种和类型，不混淆同代码不同市场。

## 行情语义
股票涨跌使用上一交易日收盘，绝不以所选曲线区间起点代替昨收。24小时加密涨跌与股票日涨跌分开标注。市场状态来自供应商交易窗口，保留时区和实际行情时间。统计缺失用横线，不猜市值。图表切换1日/1周/1月/3月/1年/全部；无法提供区间明确提示。价格不等同交易建议或可成交报价。

## 验证与交付
真实接口冒烟；解析/昨收/时间/空值/限流/失败缓存单元测试；手机375/390、平板834、桌面1487布局；隔离Playwright测试搜索/添加/删除/排序/切换图表/旧请求/本地隔离/导入导出。参考图与实际页面同输入比较并记录design-qa.md。单容器非root，最简Docker命令，无强制Key。MIT开源与各来源归属说明分开。
