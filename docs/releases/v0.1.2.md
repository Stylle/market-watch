# v0.1.2

- 支持 A 股、境内指数与 ETF 的中文名称、拼音缩写及代码搜索；新增沪深300等常用指数。
- 东方财富报价与历史适配，腾讯财经独立后备来源；按实际来源标注，不复权，成交量单位为手。
- 修复普通按钮点击后的悬停残留；保留当前标的与筛选项的必要高亮。
- 首次报价失败显示横线，不再误显示零价格。分时来源不可用时提示切换日线区间。
- 保留原有浏览器自选、偏好与导入格式，无需迁移或新增环境变量。

## 更新

将 Compose 镜像改为 `stylle/market-watch:v0.1.2`，然后执行：

```sh
docker compose pull
docker compose up -d
```

保持原访问地址不变，自选仍保存在当前浏览器。
