# Agent handbook
Read README.md and docs/DATA-SOURCES.md. This repository is independent. Keep user watchlists/preferences entirely device-local. Do not add accounts or server persistence of watchlists. Public market data caching is memory-only and bounded. Never log query bodies or secrets. No fake production prices, fabricated missing stats or substituted spot/futures quotes. Respect provider limits, distinguish quote currency/time/session, use previous trading-day close for equities. GOLD_API_KEY remains server-side. Build frontend before Go embeds web. Run backend/frontend tests and browser layout/interaction checks for changes. No release until built images and sources are validated.
