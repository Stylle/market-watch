# 观市 · Market Watch

自托管的多市场投资观察工具：股票、指数、ETF、加密货币与现货贵金属放在同一份设备自选中。深色双栏界面，桌面看列表与图表，手机在自选和详情间切换。

## 功能

- 最多50个自选；搜索名称、代码和交易所，支持中文常用别名；添加、删除、排序和类型筛选。
- A 股股票、指数、ETF 支持中文名称、拼音缩写和代码搜索，例如“沪深300”“茅台”“HS300”。A 股报价与历史曲线使用东方财富公开接口，按昨收计算涨跌；历史为不复权，成交量单位为手。接口不可用时明确提示，不生成模拟价格。
- 股票保持交易所和币种身份，港股 0700 与其他市场的相同数字代码互不混淆。GBp 为英镑便士，不等于 GBP。
- 真实报价、折线图、成交量、区间切换、触控/滚轮缩放；缺少历史或统计会明确提示，不生成假数据。
- 股票涨跌对比上一交易日收盘；加密为特定 Coinbase USD 交易对的24小时涨跌；现货不冒充期货。现货单位为美元/金衡盎司。
- 自选、排序、选中项、主题、涨跌配色和刷新间隔只存在当前浏览器 localStorage，支持JSON导入导出，不建账号、不保存服务端自选。
- 行情在服务端按需请求，只有有上限的公开行情内存缓存；不持久化查询清单或请求正文。反向代理日志由部署者自行管理。

## 部署

Go单进程内嵌Vue前端，无数据库。最简部署：

```sh
docker run -d --name market-watch --restart unless-stopped -p 28185:8080 stylle/market-watch:v0.1.3
```

访问 `http://服务器:28185`。镜像支持 `linux/amd64`、`linux/arm64`；提供版本标签 `v0.1.3` 和 `latest`。也可使用仓库 `compose.yaml` 执行 `docker compose up -d`。无须登录或配置强制Key。所有自选保存在设备端；不需要挂载数据卷。更换域名/协议/端口属于不同浏览器存储空间，可先导出偏好后导入。

现货黄金/白银**当前报价免Key**；历史曲线可选配置环境变量 `GOLD_API_KEY`，见 [Gold API文档](https://gold-api.com/docs)。不配置时仍能看现货价，图表会提示需要Key。免费历史接口每小时共享10次额度，应用按部署实例预留余量、最多9次/小时，并缓存区间结果；别在不同实例共用同一Key后高频刷新。密钥只通过服务端请求头使用，不传到浏览器。

容器非root UID/GID 10001，默认8080。可用 `LISTEN_ADDR` 改监听地址。公网部署可在反向代理增加HTTPS和访问控制。不要把个人数据源Key写入源码或偏好文件。

## 行情来源与边界

- **股票、指数、ETF、期货**：Yahoo Finance公开接口，query1/query2为同来源线路；个人自托管实验性适配，没有承诺全市场覆盖或实时授权。接口可能变化、受地区限制、限流。公开或商业部署前须核实授权并按需要替换为有许可的数据提供商。当前来源暂不可用时不会静默造价。
- **A 股、境内指数与 ETF**：东方财富公开搜索、报价、K 线接口；无须 Key，不承诺实时性或持续可用性。保留已有 `.SS` / `.SZ` / `.BJ` 自选代码，沪深同码标的互不混淆。1 日显示最近交易日的 5 分钟线，全部显示来源可提供的月线；交易状态未提供时如实显示。数据使用及转发授权由部署者核实。
- A 股报价或历史接口连接失败时自动尝试腾讯财经后备来源，并标注实际来源；两者均不可用时明确提示，不用模拟数据填补。分时不可用时建议切换日线区间；首次报价失败显示横线，不显示零价格。
- **加密货币**：Coinbase Exchange公开市场数据；USD现货交易对不等于USDT或全市场综合价，24小时基准来自交易所stats。数据时间标注为获取时间。当前历史最长3个月；没有冒充“全部历史”的截断曲线。
- **现货黄金/白银**：Gold API。当前报价更新约30秒，应用缓存60秒；历史日线需Key，展示为日均价。黄金期货 `GC=F` 单独列为期货，不作为现货失败回退。
- 只展示供应商实际返回的统计；无市值、缺少昨收时显示横线。公开参考行情可能延迟、不可用于保证成交。

应用默认每分钟刷新，后台标签页暂停轮询。共享缓存、同标的请求合并、网络并发上限、来源限流冷却与旧报价提示可减少上游负担。当前缓存不跨进程、不跨容器共享。

来源、许可和接口说明见 [DATA-SOURCES](docs/DATA-SOURCES.md)。

## 开发与检查

需要 Go 1.26.11+、Node.js 24+：

```sh
cd frontend
npm ci
npm test
npm run build
cd ..
go test ./...
go vet ./...
LISTEN_ADDR=127.0.0.1:28185 go run .
```

最后一行是POSIX shell写法；PowerShell先设置 `$env:LISTEN_ADDR='127.0.0.1:28185'`，再执行 `go run .`。前端开发 `npm run dev` 代理到28185。健康端点 `/healthz`。

`docker build --target test .` 在Linux运行race detector与vet。`web/.keep` 供纯后端单元测试使用，生产前须构建前端。项目MIT开源，第三方资产保持原许可。


源码本地打包：`docker build -t market-watch:local .`。
